# Local GitHub upload bundle — Group 09

This folder contains the original Python training/extraction/repair scripts, all 9 runs' lightweight JSON/CSV records, figures, and data audit summaries. **No dataset images or model checkpoints are included.**

These items have not automatically been pushed to GitHub from this bundle. GitHub contains a base README and project documentation already. Copy these folders into a clone of the repository, inspect files for local paths or sensitive data, then run `git add src results figures dataset_metadata paper` and commit/push.

**Important:** The proposed manuscript in `paper/` contains a results-table fragment only; the original ACM main LaTeX source remains a separate document.

The cleaned manifest is included with portable paths beginning `local_pilot_clean/images/...`. The source image files must be obtained separately; no photographs are included.
